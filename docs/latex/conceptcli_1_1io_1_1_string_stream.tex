\doxysubsection{Detailed Description}
A String\+Stream is used to write a string of characters to an unbuffered output stream. 

It is a callable that takes a \doxylink{classcli_1_1_byte_view}{cli\+::\+Byte\+View} as input and returns a cli\+::\+Error to indicate write success.
