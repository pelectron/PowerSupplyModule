\doxysubsection{Detailed Description}
\subsubsection*{template$<$typename T$>$\newline
class psm\+::\+Result$<$ T $>$}
An optional-\/like type which either contains a T, or a \doxylink{namespacepsm_aa45c0938ecc6e6db1cf0d7ecc5c43abe}{psm\+::\+Error} value. 

Wether the \doxylink{classpsm_1_1_result}{Result} contains a value can be queried with operator bool() or \doxylink{classpsm_1_1_result_a6056c2f8e53ac8d98df45eea59414d00}{has\+\_\+value()}. The value of the result, if it contains a value, can be retrievied with value(). The error can be retrieved with \doxylink{classpsm_1_1_result_a64c7ca0248ab18602dd6fc51315078cf}{error()}.

If T is trivial, i.\+e. trivially default constructible and trivially destructible, then \doxylink{classpsm_1_1_result}{Result} is completely constexpr from c++17 onward. In c++20 and above, the whole class is constexpr, even for non trivial types.
