\doxysubsection{Detailed Description}
A Getter G retrieves the value of a parameter. 

An instance of G must be callable with an l value reference and return a cli\+::\+Error. The reference denotes the place where the getter should store it value. If G cannot produce a value, it should return the error that occurred.
