\doxysubsection{Detailed Description}
Specialization of \doxylink{classpsm_1_1_result}{Result} for void. 

The value cannot be retrieved, only the error.

The main difference between Result$<$\+T$>$ and \doxylink{classpsm_1_1_result_3_01void_01_4}{Result$<$void$>$} is the default constructed state. A default constructed Result$<$\+T$>$ is erroneous, i.\+e. it does not have a value. A default constructed \doxylink{classpsm_1_1_result_3_01void_01_4}{Result$<$void$>$} "{}has"{} a value, i.\+e. it is constructed with the error \doxylink{namespacepsm_aa45c0938ecc6e6db1cf0d7ecc5c43abea334c4a4c42fdb79d7ebc3e73b517e6f8}{Error\+::none} and operator bool() and \doxylink{classpsm_1_1_result_3_01void_01_4_a159b5a5682c4c40761f570207b2b585b}{has\+\_\+value()} return true.
