\doxysubsection{Detailed Description}
\subsubsection*{template$<$size\+\_\+t Int\+Digits, size\+\_\+t Frac\+Digits$>$\newline
class psm\+::signed\+\_\+fixed$<$ Int\+Digits, Frac\+Digits $>$}
Signed fix point type with basic math and formatting support. 

Holds its value in two\textquotesingle{}s complement, unused upper bits are 0 (not sign extended).

The operations this type supports are the follwoing\+:
\begin{DoxyItemize}
\item conversion to and from float and double
\item conversion to and from bit pattern
\item addition, subtraction, multiplication and division only using integer math.
\item formatting with to\+\_\+chars(). See "{}sgl/format.\+hpp"{}.
