\doxysubsection{Detailed Description}
This class represents an ansi input device, e.\+g. 

a keyboard or UART input stream, and is used to send events to the cli.

It processes data character by character.

Function\+:
\begin{DoxyItemize}
\item handle special ascii characters (DEL/\+BS/\+ESC/tabs/feeds)
\item handle a basc set of ansi escape sequences
\end{DoxyItemize}

To use it, construct it with a reference to the cli and call on\+\_\+char() in your input stream receive callback, for example your UART handler.
