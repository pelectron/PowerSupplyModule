\doxysubsection{Detailed Description}


Arguments are the elements that describe c++ function arguments. These argument specifications are then used by Functions to parse the char input into the specified values and validate them.

There are two kinds of function arguments\+:


\begin{DoxyItemize}
\item required\+: these parameters must be specified, else it is an error.
\item optional\+: these parameters can be left out because they have a default value.
\end{DoxyItemize}

Arguments are fully specified by their\+:


\begin{DoxyItemize}
\item name\+: the human readable name
\item description\+: a string that is used by the help functionality
\item type\+: the value type of the argument
\item parser\+: used to parse a value the arguments type
\item validator\+: used to validate a parsed value
\item optionally, a default value
\end{DoxyItemize}

\doxylink{group__optional-args_gaaa32d3f116868dcdf0e27a5884bcf8e8}{cli\+::funcs\+::arg} is the templated overload set (sounds horrible, but bear with it) to use for creating arguments. There are two main templates forms, one for required and one for optional arguments.
