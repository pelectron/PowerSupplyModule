\doxysubsection{Detailed Description}
This file provides a CLI enginge to build a remote interface upon a byte stream. 

The basics\+:
\begin{DoxyItemize}
\item the cli is a hierarchical tree of commands
\item a command has the following properties\+:
\begin{DoxyItemize}
\item a name\+: a string to identify the command
\item a description\+: a string to display for help messages
\item the function to execute
\item and optionally, any amount of sub commands
\item the command sequence\+: this sequence specifies the command to execute
\item the arg sequence\+: this sequence specifies the command\textquotesingle{}s arguments
\end{DoxyItemize}
\item the root is owned by the \doxylink{classcli_1_1_cli}{Cli} structure.
\item commands with the root as parents are called root commands.
\end{DoxyItemize}

c++ syntax\+: {\ttfamily auto my\+\_\+cli = cli\+::cli(config, commands...);} a command\+: {\ttfamily cli\+::cmd("{}\mbox{[}any.\+path.\mbox{]}name"{}, func)}\+: a "{}free function"{} command. This cannot have subcommands. {\ttfamily cli\+::cmd("{}\mbox{[}any.\+path.\mbox{]}name"{}, obj\+\_\+reference, sub\+\_\+commands...)\+: an "{}object"{} command is added. This must have subcommands }cli\+::cmd("{}\mbox{[}any.\+path.\mbox{]}name"{}, const\+\_\+obj\+\_\+reference, get)\+: a retrievable parameter is added.
