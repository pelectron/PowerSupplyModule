\doxysubsection{Detailed Description}
This file contains the utilities to create parameters, namely the functions\+: 


\begin{DoxyItemize}
\item param(..)\+: creates a parameter
\item obj(...)\+: creates a parameter, and further also accepts member functions and member data as subcommands. member functions are created with \doxylink{group___functions_gacf55204507a85fa59808754b48b953f5}{cli\+::funcs\+::mem\+\_\+fun()}.
\item mem\+\_\+data(...)\+: Creates a member data command, inteded to be used with obj(...).
\end{DoxyItemize}

and the concepts\+:
\begin{DoxyItemize}
\item Getter/\+Getter\+Of\+: parameter getters/accessors
\item Setter/\+Setter\+Of\+: parameter setters 
\end{DoxyItemize}
