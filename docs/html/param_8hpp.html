Detailed Description

This file contains the utilities to create parameters, namely the functions:

  • param(..): creates a parameter
  • obj(...): creates a parameter, and further also accepts member functions and member data as subcommands. member functions are created with cli::funcs::mem_fun().
  • mem_data(...): Creates a member data command, inteded to be used with obj(...).

and the concepts:

  • Getter/GetterOf: parameter getters/accessors
  • Setter/SetterOf: parameter setters
