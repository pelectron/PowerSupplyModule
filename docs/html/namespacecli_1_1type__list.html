◆ merge_t

template<class... Lists>
using cli::type_list::merge_t = typename merge<Lists...>::type

merges Lists into a single type list.

If sizeof...(Lists) is 0 then an TypeList<> is returned. If a mixture of type list templates is used, e.g. mixing TypeList with std::variant and std::tuple, then the result will use the template of the first element in Lists.

Template Parameters
Listsa pack of type lists
